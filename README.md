\# 영화 제목 자음 퀴즈



영화 제목의 자음만 보고 영화 제목을 맞히는 파이썬 콘솔 퀴즈 게임입니다.



\## 퀴즈 주제 선정 이유



영화를 좋아하고, 자음만 보고 제목을 추측하는 방식이 재미있어서 영화 제목을 주제로 정했습니다.



\## 실행 방법



```bash

python main.py

```



\## 현재 기능



\- 영화 제목 자음 퀴즈 프로젝트 시작

\- Python 실행 확인
