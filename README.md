# 영화 제목 자음 퀴즈

## 프로젝트 개요

영화 제목의 자음만 보고 영화 제목을 맞히는 파이썬 콘솔 퀴즈 게임입니다.

## 퀴즈 주제 선정 이유

영화를 좋아하고, 영화 제목을 자음만 보고 추측하는 방식이 재미있어서 영화 제목을 주제로 정했습니다.

## 실행 방법

PowerShell에서 다음 명령어를 실행합니다.

```bash
python main.py
```

## 기능 목록

- 영화 제목 자음 퀴즈 풀기
- 새로운 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- 잘못된 입력 처리
- `q`를 입력해 퀴즈에서 나가기
- 퀴즈와 점수 저장
- 프로그램 재실행 후 데이터 불러오기

## 파일 구조

```text
movie-consonant-quiz/
├── main.py
├── README.md
├── .gitignore
└── state.json
```

## 데이터 파일 설명

`state.json`은 프로젝트 루트에 저장됩니다.

- `quizzes`: 퀴즈 목록
- `best_score`: 최고 정답 수

## 사용한 클래스

- `Quiz`: 하나의 퀴즈를 관리합니다.
- `QuizGame`: 게임 진행, 저장, 불러오기를 관리합니다.
